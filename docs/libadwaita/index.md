# Libadwaita 1.x (latest) — Overview

Version: 1.x (latest; via upstream Libadwaita docs)

Summary
- Libadwaita (Adw) provides building blocks for modern GNOME apps on GTK4. It offers adaptive widgets, style helpers, dialog primitives and recommended patterns for sidebars, boxed lists, and responsive layouts.
- Key concepts: AdwApplication / adw_init(), adaptive breakpoints, AdwNavigationSplitView / AdwOverlaySplitView, AdwDialog, AdwToolbarView, style classes and CSS variables.

Use this folder for implementation guidance; consult the full upstream docs for API details.

See also: boxed-lists.md, adaptive-layouts.md, styles-and-appearance.md, css-variables.md, style-classes.md

Widgets: see `widgets/INDEX.md` for per-widget practical summaries and upstream links.
