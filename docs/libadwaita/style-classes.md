# Style Classes

Commonly-used classes
- .accent, .success, .warning, .error — change the accent color and are available on many widgets.
- .boxed-list, .boxed-list-separate — boxed list appearance for list boxes.
- .toolbar, .spacer, .dimmed, .inline — various utility appearance helpers.
- Typography: .title-1 .. .title-4, .heading, .document, .body, .caption, .monospace.

Deprecated
- The docs list several deprecated style classes such as `.content`, `.sidebar`, `.app-notification`, `.large-title`, `.opaque`, `.dim-label`. Avoid using these; prefer replacements (e.g., `.navigation-sidebar`, `.boxed-list`).

Practical: prefer style classes over hard-coded CSS rules for widget appearance and semantics.
