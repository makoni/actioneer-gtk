# Migrating to Breakpoints

Summary
- Breakpoints (AdwBreakpoint) replace many older responsive widgets. Use breakpoints to change widget properties or layout based on width/height.
- Replace old patterns with AdwToolbarView, AdwWindow / AdwApplicationWindow and AdwNavigation* widgets. Use AdwNavigationSplitView / AdwOverlaySplitView for sidebars and utility panes.

Practical: when updating UI to be adaptive, introduce breakpoints and convert header/toolbars into AdwToolbarView for automatic style handling.

Upstream: https://gnome.pages.gitlab.gnome.org/libadwaita/doc/1-latest/migrating-to-breakpoints.html
