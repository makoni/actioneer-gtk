# AdwEntryRow

Short summary: A row with a labeled text entry for preference-like forms.

Usage:
- Use `adw::EntryRow::new()` and access the inner `gtk::Entry` via `entry()` to read/write text.
- Useful inside `AdwPreferencesWindow` or forms where a compact labeled entry is desired.

Upstream: https://gnome.pages.gitlab.gnome.org/libadwaita/doc/1-latest/widgets/entry-row.html
