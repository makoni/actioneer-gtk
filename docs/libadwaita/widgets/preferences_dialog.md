# AdwPreferencesDialog / PreferencesGroup / PreferencesPage

Purpose
- PreferencesDialog is the modern preferences UI container. PreferencesGroup groups boxed-list rows; PreferencesPage is a single page inside preferences.

Practical tips
- Use `AdwPreferencesGroup` to group related settings; `separate-rows` property adds separators.
- Note: some older subpage APIs are deprecated — prefer navigation-based subpages and AdwNavigationPage for hierarchical preferences.

Upstream: https://gnome.pages.gitlab.gnome.org/libadwaita/doc/1-latest/class.PreferencesDialog.html
