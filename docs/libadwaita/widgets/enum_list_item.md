# AdwEnumListItem

Purpose
- Represents an item in an enum list; typically used together with `AdwEnumListModel` for listing enumerated options in preferences.

Practical tips
- Prefer AdwEnumListItem with AdwEnumListModel when building settings that expose a finite set of choices.
