# AdwToastOverlay

Short summary: A lightweight overlay for showing transient toast notifications at the top of a window.

Usage notes:
- Create once per window and call `show_toast()` to present messages. Toasts auto-dismiss after a short duration.
- Use for low-priority, contextual messages that don't require modal attention.

Upstream: https://gnome.pages.gitlab.gnome.org/libadwaita/doc/1-latest/widgets/toast-overlay.html
